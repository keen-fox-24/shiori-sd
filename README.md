# 詩織 Stable Diffusion（SDXL）導入計画

作成: 2026-11-18

## 結論（採用ルート）
**Kaggle Notebook の無料GPUで SDXL を使う。**

理由（2026-11-18 に検索で確認、変動ありうる）:
- Kaggle: クレジットカード不要、電話番号認証のみ。無料GPU は T4 x2（各16GB）、週 約30時間、1セッション最大12時間、リセットは週次。
- Modal: 月$30分のクレジットがあるが、GPU利用に支払い方法の登録が必要という報告があり、「元手ゼロ・カード登録なし」の方針と合わないため主ルートにしない。
- Google Colab 無料枠: クォータ非公開で不安定、無料枠ではWeb UI（ComfyUI等）のトンネル利用が制限される報告があるため主ルートにしない。
- お姉さんの作業VM: GPUなし、メモリ約8GB のため、SDXLの生成・学習はローカルでは実用的でない（確認済み）。

## 進め方
1. [済] 学習用データセット seed 7枚 + キャプションを作成（dataset/）
2. [次] データセットを 15〜20枚まで増やす（表情・角度・服装・場所をばらけさせる）
3. [君の作業・1回だけ] Kaggleアカウント登録 + 電話番号認証（GPUとインターネットが有効化される）
4. ノートブック（kaggle/train_shiori_lora_kaggle.ipynb）を Kaggle で実行
   - データセットの受け渡しは GitHub 経由に決定（2026-11-18、ユーザー選択）: 公開リポジトリ https://github.com/keen-fox-24/shiori-sd に shiori-dataset.zip を置き、ノートブックが自動で clone + 展開する。理由: Kaggle Web UI のファイル選択が自動ブラウザで開けず、UIアップロードができなかったため。
   - ベースモデル候補: Animagine XL 4.0（SDXL系・アニメ向け）
   - 学習: kohya sd-scripts、T4 16GB向け設定（1024px、batch 1、8bit optimizer、fp16）
5. できたLoRAでテスト生成（外出・カフェ・部屋など）→ 顔の一致具合を確認して調整

## 注意
- 無料枠の条件は変わることがある。実行前に Kaggle の Settings で残りクォータを確認する。
- 課金が発生する操作はしない。Kaggleはカード登録自体が不要なのが採用理由。
- 学習画像はすべて架空キャラクター「詩織」の生成画像。実在人物の写真は使わない。
